## How it connects

**Research → choose useful work → develop and try it → document what happened → share it → improve it.**

- **Skill Factory** is the private workshop for reusable skills.
- **MVskill-ops** helps create and improve those skills.
- **MVgrillz** helps plan when the direction needs working through.
- **hermgainz** is a separate skill project, not another factory.
- **The AI Research Engineer Lab** supplies relevant research.
- **Builder** helps develop and document the work.
- **Maya** turns documented work into content drafts.
- **I choose the direction and what represents me publicly.**
